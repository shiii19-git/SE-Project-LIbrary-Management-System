# Library Management System

A simple library management system built with plain HTML, CSS and JavaScript. No frameworks or installation needed.

## Features
- Add a book (title, author, category)
- View all books in a table
- Search by title, author or category
- Issue a book to a member (due date is set to 14 days)
- Return a book
- Delete a book
- Live counts of total, available and issued books
- Data is saved in the browser (localStorage)

## How to run
Open `index.html` in any web browser.

## Files
- `index.html` - page structure
- `style.css` - styling
- `script.js` - all the logic
